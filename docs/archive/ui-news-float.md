# 新闻浮卡遮挡持仓修复

状态：已完成（2026-10-31）

## 现象
新闻浮卡固定在屏幕底部中间（桌面 420px 宽、手机全宽），滚动到持仓区时会盖住持仓卡片。

## 改动
1. 桌面（≥1080px）：浮卡恢复右下角固定，宽度收窄到 300px，正好落在右栏范围内，不再压住中栏的持仓列表；只覆盖右栏底部风险席。
2. 单列/手机（≤1079px）：不再浮出卡片（`display: none`），快讯改由图表卡片内的「快讯」条和「新闻中心」承载，避免任何遮挡。
3. `?v=20261031d` 更新缓存版本号，保证手机端拿到新样式。

## 验证
- Playwright 1440×900 / 1272×786 / 1080×720：浮卡矩形完全落在右栏内，与持仓列表无交叠；
- 1000×700 / 390×844：浮卡不显示，持仓完整可见；
- `tools/test-ui.mjs` 冒烟通过，0 console 错误。
