# 任务计划：前端改为 Claude 风格

日期：2026-10-31

## 目标

在不改动游戏逻辑与布局结构的前提下，把 `kurumi` 前端视觉改成 Claude（Anthropic）产品风格：暖纸底、陶土橙主色、衬线标题、克制边框与柔和圆角；同时保留游戏原有的日夜主题与红涨绿跌切换。

## 实现

- [x] 新增 `css/claude.css`，在 `extra.css` 之后加载，只覆盖视觉细节。
- [x] `tokens.css` 追加 Claude 调色板：浅色暖纸（#F5F4EE / #FBFAF7 / #262624）与深色墨底（#1F1E1D / #262624 / #F5F3EC），主色陶土橙 #C96442 / #D97757。
- [x] 字体：标题使用衬线栈（Tiempos / Source Serif / 宋体），正文使用系统无衬线，数字保留等宽与 tabular-nums。
- [x] 组件：顶栏/账户条改为纸面底色无重阴影；面板 16px 圆角；胶囊分段控件；陶土色主按钮与描边次按钮；买/卖按钮改为陶土橙与鼠尾草绿实心。
- [x] 图表改为浅色纸面（深色主题为暖炭黑），K 线、均线、强平价、成交量全部走新令牌。
- [x] 分享卡同步 Claude 配色。
- [x] 品牌标记改为自绘 SVG：字母 A（ABYSS）+ 横向蜡烛实体，单色陶土橙；favicon 与 Android 启动图标同步。
- [x] 默认主题改为浅色（已保存过夜间偏好的用户保持原设置）；设置项文案改为「浅色 / 深色」。
- [x] 顺带修复：货币对列表与持仓/挂单列表改为结构化 key 更新，避免行情 tick 重建 DOM 导致移动端点击丢事件（切换不了货币对、平不了仓）。

## 验证

- Playwright：1440 桌面 / 390 移动端、浅色 / 深色、红涨绿跌，截图检查；控制台 0 错误。
- 全流程冒烟测试 `tools/test-ui.mjs` 通过（下单、平仓、挂单、战役、挑战、分享、移动端）。
- Android APK 已重新构建：`dist/abyss-fx-1.0.apk`。

## 未决

- 字体使用系统字体栈，不同平台（Windows / macOS / Android）的衬线标题观感会略有差异；如要完全一致需内置字体文件。
- 浅色主题的图表刻度线较细，低亮度屏幕下可能偏淡，可按反馈调整。
