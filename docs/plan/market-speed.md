# 行情倍速增加 0.25× / 0.5×

状态：已完成，待用户确认（2026-10-31）

## 需求
用户反馈默认行情速度偏快，希望增加更慢的倍速档位。

## 改动
1. `index.html`：`#speedSeg` 增加 `0.25×`、`0.5×` 两个按钮（顺序 0.25 / 0.5 / 1 / 2 / 4）。
2. `js/core/game.js`：
   - 新增 `_speedAcc` 累加器。`_loop()` 每 100ms 累加 `this.speed`，
     满 1 才执行一次 `_simStep()`，余数留到下一轮，因此 0.25× = 每 400ms 走一步；
   - 只有实际执行过步进时才 `emit('tick')`，慢速下不做无谓重绘；
   - 构造 / 恢复存档 / `setSetting('speed')` 时清零累加器，避免切换倍速时带进旧余数。
3. `index.html` 资源版本号 bump 到 `?v=20261031g`。

## 验证
- 390×844 / DPR 3 移动视口，2 秒内 tick 数：0.25× → 5，0.5× → 10，1× → 20（2×/4× 仍是每轮一次 tick，与改动前一致）。
- 工具栏 5 档 + 财经日历 + 重置视图在 390px 宽度下仍单行排布，无溢出。
- `tools/test-ui.mjs` 全流程冒烟通过，0 console 错误。

## 待确认
- 用户在手机/桌面上确认 0.25× 的观感是否合适；若仍偏快，可再补 0.1× 或改成滑杆。
